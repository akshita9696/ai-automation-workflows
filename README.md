## How I build them

- **A person approves anything sensitive.** AI drafts, people decide: replies wait for approval, complaints and refunds go straight to a person.
- **AI answers from real data.** The support agent only answers from the business's own documents, and hands over if it can't.
- **Every failure has a plan.** If an AI call or a tool fails, the workflow falls back, alerts the owner or retries. Nothing fails silently.
- **People are treated fairly.** Opt-outs are permanent, chasing stops the moment someone replies, and everyone gets the same review request.
- **Every outcome is logged,** so there is always a record of what happened and why.

## Use them yourself

Each folder has a README explaining the system step by step, plus the workflow files. In n8n, choose **Import from File**, attach your own accounts and replace the placeholders (`you@example.com`, `appXXXXXXXXXXXXXX`, `YOUR_...`). Email addresses, IDs and links have been replaced, and no passwords or API keys are included.
